# Q09 - Check Leap Year

## Problem
Read a year and print `Leap Year` if it is a leap year, otherwise print `Not a Leap Year`. A year is a leap year if it is divisible by 4 and not by 100, or if it is divisible by 400.

## Example

**Input**
```
2024
```

**Output**
```
Leap Year
```
