# Q26 - Anagram Check

## Problem
Read two strings on two lines and print `Anagram` if they are anagrams of each other, otherwise `Not Anagram`. Comparison is case-insensitive and ignores spaces.

## Example

**Input**
```
listen
silent
```

**Output**
```
Anagram
```
