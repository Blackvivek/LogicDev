# Q50 - FizzBuzz

## Problem
Read an integer `n` and print numbers from 1 to `n`, one per line, with these rules: multiples of 3 print `Fizz`, multiples of 5 print `Buzz`, multiples of both print `FizzBuzz`, otherwise print the number itself.

## Example

**Input**
```
15
```

**Output**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
