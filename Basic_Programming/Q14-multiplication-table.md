# Q14 - Multiplication Table

## Problem
Read an integer `n` and print its multiplication table from 1 to 10 in the form `n x i = result`.

## Example

**Input**
```
3
```

**Output**
```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```
