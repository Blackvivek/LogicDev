# Q07 - Simple Interest

## Problem
Read principal `P`, rate `R` (percent per year) and time `T` (years). Print the simple interest using `SI = (P * R * T) / 100`.

## Example

**Input**
```
1000 5 2
```

**Output**
```
100
```
