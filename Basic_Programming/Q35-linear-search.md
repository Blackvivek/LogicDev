# Q35 - Linear Search

## Problem
Read `n`, `n` integers, then a target `t`. Print the 0-based index of the first occurrence of `t`, or `-1` if `t` is not present.

## Example

**Input**
```
5
10 20 30 40 50
30
```

**Output**
```
2
```
