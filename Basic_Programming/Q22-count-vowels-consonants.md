# Q22 - Count Vowels and Consonants

## Problem
Read a string of English letters and print two lines: `Vowels: X` and `Consonants: Y`. Treat `a, e, i, o, u` (any case) as vowels; ignore non-letter characters.

## Example

**Input**
```
Programming
```

**Output**
```
Vowels: 3
Consonants: 8
```
