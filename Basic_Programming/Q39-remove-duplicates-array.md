# Q39 - Remove Duplicates from Array

## Problem
Read `n` followed by `n` integers and print the array with duplicates removed, preserving the original order, space separated.

## Example

**Input**
```
7
1 2 2 3 4 4 5
```

**Output**
```
1 2 3 4 5
```
