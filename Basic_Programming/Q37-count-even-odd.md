# Q37 - Count Even and Odd Numbers

## Problem
Read `n` followed by `n` integers and print two lines: `Even: X` and `Odd: Y`.

## Example

**Input**
```
6
1 2 3 4 5 6
```

**Output**
```
Even: 3
Odd: 3
```
