# Q41 - Star Pyramid Pattern

## Problem
Read an integer `n` and print a centered pyramid of stars with `n` rows. Row `i` (1-indexed) has `2*i - 1` stars, padded with leading spaces so the pyramid is centered.

## Example

**Input**
```
4
```

**Output**
```
   *
  ***
 ***** 
*******
```
