# Q45 - Armstrong Number

## Problem
Read an integer and print `Armstrong` if it equals the sum of its own digits each raised to the power of the number of digits, otherwise print `Not Armstrong`. Example: 153 = 1^3 + 5^3 + 3^3.

## Example

**Input**
```
153
```

**Output**
```
Armstrong
```
